## Project Spotlights

<details>
<summary><b>🤖 Agentic Cost Analyzer — FastAPI + Streamlit + LLM Routing</b></summary>

### The question
Frontier models are expensive to run for every single prompt. Most of them
don't need a frontier model at all.

### What it does
- Scores prompt complexity from structural signals (length, code fences, planning language), no LLM call needed to make that decision
- Routes each prompt to a cheap or frontier tier and attributes it to one of six named agent personas
- Dispatches a real call through OpenAI, Anthropic, or Hugging Face's free inference tier, with a clearly labelled mock fallback when no key is set
- Counts tokens exactly with `tiktoken` or provider-reported usage, and prices every request against a small pricing catalog
- Tracks usage per account with Prometheus metrics and a Grafana dashboard underneath

🔗 [View repository →](https://github.com/midhulms/Agentic-cost-Analyzer) · [Try the live demo →](https://agentic-cost-analyzer-ld6uxpsuecoytdpat7grg3.streamlit.app/)

</details>

<details>
<summary><b>📊 Retail Analysis Sales Dashboard — Power BI</b></summary>

### What it solves
Most retail dashboards report what happened. This one is built so a district
manager can see where to look next, in under 30 seconds, without an analyst
in the loop.

### Key features
- District manager slicer for fast store-level triage
- 10-category bubble chart mapping average $/unit against sales variance, to flag price-misaligned categories
- YoY area chart surfacing seasonal patterns (March spike, late-summer dip) instead of treating them as noise
- Reusable DAX measures for variance %, YoY comparisons, and average $/unit

🔗 [View repository →](https://github.com/midhulms/Retail-analysis)

</details>

<details>
<summary><b>📈 Enterprise AI Adoption & Productivity Analysis — Python + Regression</b></summary>

### The question
Does enterprise AI adoption actually move labour productivity, or is the
relationship weaker than the headlines suggest?

### What I did
- Collected and cleaned 80 quarters (2006–2025) of US Bureau of Labor Statistics productivity data
- Matched it against enterprise AI adoption rate over the same period
- Fitted an OLS regression (R² = 0.786) and isolated the Q1 2020 outlier as a COVID-era anomaly rather than folding it into the trend
- Produced visualisations showing AI adoption growing quickly while productivity has stayed comparatively flat

### Finding
Despite 70%+ growth in enterprise AI adoption since 2019, labour productivity hasn't moved proportionally, most likely due to adoption friction, skill gaps, and measurement lag rather than a limit on the technology itself.

🔗 [View repository →](https://github.com/midhulms/Enterprise-AI-Adoption-Productivity-Analysis)

</details>
